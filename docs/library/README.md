# Library

Index of the reference sets in this library. Open a set when the work needs it.

| Set | Function |
|-----|----------|
| [platforms/](platforms/README.md) | Language and operating-system packs, plus tool configs for Python, Rust, and C/C++ |
| [archive/](archive/README.md) | Retired procedure packs. Not loaded for a task |
| [kit-adopter/](kit-adopter/README.md) | Adopt order and upgrade order. Open one pack when that step is the task |
| [kit-skill-template/SKILL.md](kit-skill-template/SKILL.md) | Verb frontmatter reference. Kept for a later skill |
| [agent-skills/](agent-skills/README.md) | Orchestrator, execute, and check packs. Open one pack when that step is the task |

The kit does not restate these sets. `kit/RULES.md` is the maintenance hub.
