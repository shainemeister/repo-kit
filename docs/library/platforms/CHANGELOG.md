History of the platform packs. The summary rule is the [changelog](../../../kit/RULES.md#changelog) sentence.

## dev-policy

### [1.1.0] - 2026-10-02

macOS joins the tree as four packs on the Linux axes, with direct distribution as the primary map and the Mac App Store packs covering the store payload and the review queue.

### [1.0.0] - 2026-08-29

Linux, Rust, Python, C, and Node share this tree, with each language OS pack under that language and the frozen archive snapshots kept with the family.
