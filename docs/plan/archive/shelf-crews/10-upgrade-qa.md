# Upgrade QA

The check is UPGRADE.md. That file stays the owner.

[kit-upgrade-qa](../../../library/kit-upgrade/skills/kit-upgrade-qa/SKILL.md) reads the changelog span since the adopted version and the workboard rows this upgrade registered. It reports fits, or a short fix list, and stops. It does not apply the fixes, edit the phase, or adopt. A product file is not a kit file.
