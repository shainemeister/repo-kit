# Adopt QA

The check is ADOPTER.md. That file stays the owner.

[kit-adopt-qa](../../../library/kit-adopter/skills/kit-adopt-qa/SKILL.md) reads the phase draft and the file in the File cell. It reports fits, or a short fix list, and stops. It does not apply the fixes. It does not edit the phase. It does not replace project text in [AGENTS.md](../../../../AGENTS.md). It does not carry the commit-message checks from [kit-review-change](../../../../kit/skills/kit-review-change/SKILL.md). The check stays in [ADOPTER.md](../../../../ADOPTER.md).
