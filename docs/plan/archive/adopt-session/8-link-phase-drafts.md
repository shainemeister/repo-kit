# Link the phase draft

Add a Draft cell so each phase row links its document under `docs/plan`.

The File cell stays the product file. The Draft cell is `docs/plan/<program>/<id>-<verb>.md`, or `—` when that phase has no draft. Notes do not repeat either path.

The blank in `kit/skills/kit-workboard-register/template/workboard.md` owns the columns. The register procedure fills both cells in the same change set as the draft. This program's rows use that shape.
