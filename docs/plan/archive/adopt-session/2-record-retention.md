# Record changelog retention

Record that this kit keeps three changelog sections and an adopter's changelog is not trimmed.

One sentence in `kit/rules/versioning-and-git.md`. Do not restate the summary rule in `kit/RULES.md`. This request is the explicit decision that allows the trim. An adopted repository's own changelog is a different file. `docs/library/platforms/CHANGELOG.md` is not this rule.

Also say that filing a finished program into `docs/plan/archive/<program>/` stays the procedure for a target. This kit's existing folders being deprecated does not change that step.
