# Point adopt and upgrade

Change adopt and upgrade so an existing `AGENTS.md` is condensed to the session block.

Run this after phase 5. `ADOPTER.md` step 6 no longer says to paste the block at the top and keep the project's sections. It follows the how-to-use cases in the agents template.

`kit/UPGRADE.md` step 3 no longer freezes the project's `AGENTS.md`. An upgrade refreshes the session block the same way and keeps the project's path note. `MEMORY.md` and `WORKBOARD.md` stay as they are.

Do not restate the block in either procedure. Cite the template.
