# Name the kit hub

Say in the directory-index rule that `kit/` is indexed by `kit/RULES.md`.

Add one sentence. Do not add `kit/README.md`. Do not backfill any other historical directory. The forward-only sentence stays. A procedure pack is still indexed by `SKILL.md`.
