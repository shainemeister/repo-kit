# Deprecate kit archive folders

Mark every program folder under `docs/plan/archive/` as a deprecated record of this kit.

Keep the folders, including `platform-continuity`. Do not edit the files inside them. Do not change `kit/skills/kit-workboard-archive/SKILL.md`.

`docs/plan/archive/README.md` stays the usage note: this folder is not the live todo list. Live work is root `WORKBOARD.md`. Say that these snapshots are deprecated because this repository is the adoption kit, and that a target still files its own finished program here.

Drop "read instead" links that point at `kit/rules/workboard.md` or at a changelog section older than `[3.8.0]`. A current index does not cite a missing file.

On `docs/plan/README.md`, mark each of those rows deprecated. Do not add a second row for a program that already has one.
