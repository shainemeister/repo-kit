# Platform history shape

Rewrite the platform changelog to one sentence per notable version.

`kit/CHANGELOG.md` owns the sentence. This file does not restate it. `docs/library/platforms/CHANGELOG.md` drops Keep a Changelog categories. Several commits in one day do not each earn a line. Published kit sections through `[3.0.0]` stay as published. Do not paste kit history into the platform file.
