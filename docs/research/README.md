# docs/research/ (repo-kit)

Index of kit-maintainer research notes.

Open when adding or finding investigations, spikes, or findings.

Four roles. A shipped decision stays in the record. An unpromoted proposal stays in the proposal. Repair stays in the queue. The constitution and the verb set stay in the working model.

|------|----------|----------|
| [repo-kit-rework.md](./repo-kit-rework.md) | Record | Shipped rework decisions and the owner that holds each one |
| [repo-kit-rules-enhancement.md](./repo-kit-rules-enhancement.md) | Proposal | Unpromoted forked-path check. Edge record for [path-pattern.md](../../kit/rules/path-pattern.md) |
