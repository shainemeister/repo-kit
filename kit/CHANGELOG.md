# Changelog

History of the Repository Standards Kit. The kit version is the latest dated section under `## repo-kit`. Upstream: https://github.com/shainemeister/repo-kit.

An adopting project keeps its own changelog. It records the adopted kit version in the [kit baseline](./RULES.md#kit-baseline). An entry here summarizes a notable change. This kit retains the three newest sections. Older detail stays in git history. The commit holds the detail ([versioning](./rules/versioning-and-git.md)). Patch releases that share a day with a section below are in the git history.

Upgrades: [UPGRADE.md](./UPGRADE.md).

## repo-kit

### [3.11.0] - 2026-10-19

Adopt and upgrade deploy the shelf from a short onramp and copy the current kit files, leaving the target's commits in place.

### [3.10.0] - 2026-10-19

The session file is the agents paste and replaces an existing AGENTS.md, each phase row links its draft, and this kit keeps three changelog sections without prior plan snapshots.

### [3.9.0] - 2026-10-19

Platform packs record a pin in the family table and follow the author checklist, a copied skill does not require the shelf, and the closed repair queue and the shipped rework record are deprecated.
