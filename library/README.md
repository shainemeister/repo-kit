# Library

Reference sets and skill packs. Open a set when the work needs it.

| Set | Function |
|-----|----------|
| [platforms/](platforms/README.md) | Language and operating-system packs, plus tool configs for Python, Rust, and C/C++ |
| [skills/](skills/README.md) | Procedure views an agent loads when the task matches, including the orchestrator crew |

The kit does not restate these sets. `kit/RULES.md` is the maintenance hub.
